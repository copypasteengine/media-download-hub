# Telegram 转发视频

## 使用

1. 从 Telegram 其它聊天或频道**转发视频本身**到已绑定的 Bot，也可以发送视频文件。
2. Bot 显示后台配置的全部启用分类，点击保存位置后才开始下载，也可选择「不保存」。每次独立转发都重新询问，不使用默认分类或上次选择。
3. 同一视频相册只选择一次，其后续附件沿用这一组的选择。保存提示 24 小时有效，服务重启仍保留；过期、停用或删除分类都不会自动改存到别处。
4. 「我的下载」显示任务，支持取消、重试和完成通知。平台链接仍可先点分类再发送，直接发链接使用后台默认分类。

优先按视频说明的首行有效文字命名，没有说明时使用原文件名；没有原文件名时使用 Telegram 日期和消息编号。同名文件不会覆盖。重复转发同一文件到同一分类会返回已有任务；不同分类可各保存一份。

附件保存的是 **Telegram 提供的那份文件**，不重新编码。如果发送者上传时已被 Telegram 压缩，无法还原压缩前画质；希望保留上传原文件时，请以文件方式发送。Bot 的清晰度按钮只影响 B站 / YouTube 等平台链接任务。

## 限制和较大视频

默认使用 Telegram 官方云 Bot API，单个附件下载限制为 20 MB。

Compose 已集成 Telegram Bot API 10.3 的 local 模式（aiogram ARM64/AMD64 镜像，锁定摘要）。在后台「机器人」填入从 [my.telegram.org](https://my.telegram.org/apps) 取得的 API ID / API Hash，勾选「启用 Telegram 大文件服务」并保存。无需 Telegram 个人账号登录，沿用现有 Bot Token 和绑定账号；密钥留空保留，API Hash 不回显。应用凭据包含在加密备份中。

本地模式解除云接口的 20 MB 下载限制，仍遵循项目的单文件大小、剩余磁盘空间限制及 6 小时获取文件超时。下载使用 Telegram 提供的文件大小提前检查空间；未知大小暂拒绝并提示重新转发。**上传 2000 MB 的官方说明不是下载上限**。

服务仅监听 Compose 内部网络，不开放宿主机端口。TDLib 的出站连接通过仅此进程使用的 ProxyChains 接入项目专用代理；不设置 NAS 全局代理，不需要特权容器、TUN 或 Docker socket。国内部署需先在后台选好可用代理。API 的 `--proxy` 仅用于出站 webhook，本项目不将它误用为 Telegram 下载代理。

`TELEGRAM_CACHE_ROOT` 决定缓存和 TDLib 数据库所在的宿主机目录，默认 `${STATE_ROOT}/telegram-api`，部署前须创建，建议位于外接盘。queue 与 telegram-api 共享该目录，媒体保存位置仍由分类独立配置。大文件先由 Telegram 下载到缓存，再流式写入分类目录校验并发布；空间检查保守预留缓存与成品两份大小。完成或失败会清理已打开的缓存，取消等待中的下载会重启专用 Bot API 子进程以停止传输，机器人会短暂重连。超过 24 小时的残留缓存定时清理，数据库保留。本地接口连接中断或返回临时忙碌／5xx 错误时会自动重试最多 3 次；取消操作不会重试。断线或异常重启后可能从头重新下载。

获取文件期间任务显示「Telegram 正在下载到缓存」，原生 Bot API 不提供该阶段的实时下载字节；缓存完成后显示入库进度。不能将该阶段的 0 字节误认为没工作。

第一次切换会先向旧接口调用 `logOut`，成功后保存切换状态；失败不会同时在云端和本地轮询。切回云接口可能受到 Telegram 最多 10 分钟的登录等待。切换时请先完成或取消已有 Telegram 下载。更换设备前停止旧部署，不能同时启动同一个 Bot 的两个实例；除配置备份外应迁移 `TELEGRAM_CACHE_ROOT` 的数据库目录，避免旧会话冲突。

仅发送 `t.me/频道/消息编号` 不等于转发视频；Bot 无法仅凭该链接读取个人私聊、任意频道历史或受保护内容。请打开消息后直接转发视频；来源禁止转发时，不提供绕过方式。

## 隐私与恢复

只接受已绑定本人在私聊发送的消息；转发来源不作为授权身份。任务持久化保存文件引用而非包含 Bot Token 的下载地址，重试时重新向 Telegram 获取有效下载地址。任务列表 API 隐藏文件引用；代理只影响本项目。

更换为另一个 Bot 后，旧 Bot 的文件引用无法通用；失败任务需要向新 Bot 重新转发。文件元数据进入加密备份，视频本身仍需单独备份。

参考：[Telegram File / getFile](https://core.telegram.org/bots/api#getfile)、[Local Bot API](https://core.telegram.org/bots/api#using-a-local-bot-api-server)。
